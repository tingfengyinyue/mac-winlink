# 首次连接引导设计

目标：将首次连接中分散的管理员权限、执行策略、Public 网络、防火墙来源、公钥授权和指纹核对步骤收口为三步引导，减少终端输出的人工往返。

选型：采用离线配对文件。相比要求首次 SSH 密码登录，配对文件不依赖用户知道 Windows 密码，也能在 SSH 尚未安装或被防火墙阻断时工作。相比自建常驻网络服务，它复用系统 OpenSSH，不增加新的服务入口。

流程：Mac `setup.sh prepare` → Windows `Setup-Windows.cmd` → Mac `setup.sh connect`。同一个 JSON 文件由 Windows 补齐服务器地址、账户、端口和本机主机指纹后传回，包含公钥及连接元数据，不包含私钥或密码。

Mac 侧使用 Bash 3.2、系统 plutil 与 OpenSSH；Windows 使用 PowerShell 5.1，复用现有安装器与授权器。双击入口处理一次提权和子进程执行策略；授权前说明 Windows 管理员共享密钥的权限范围。

每台 Mac 的来源地址单独限制，规则覆盖三个网络配置文件，避免 Public 网络造成隐蔽超时；仍保留已有管理员规则。主机密钥必须与可信文件中的指纹一致，不自动忽略冲突。

验证分层：隔离 Mac 客户端测试；真实 Windows PowerShell 语法与只读预检；已有 SSH 的真实授权/防火墙/回写/导入链路；全新系统首装与 UAC 交互单独验收。运行文件、配对元数据和日志均留在本机，不发布到公共源码。
